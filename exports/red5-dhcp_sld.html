Red5-DHCP — system architecture single-line diagrams

ANA InterContinental Tokyo BMS retrofit: the existing Azbil savic-netFX2 architecture and the proposed Delta / Red5 BACnet replacement, drawn on the same tier skeleton so the swap reads at a glance. One representative branch is expanded per tier with its multiplicity annotated — drawing all 67 panels would make it a wiring diagram.

Both diagrams carry a right-hand phase column for the one continuous delivery: P1 fabrication, P3 installation, P4 instruments, P5 programming. Tiers marked none are reused or retained.
